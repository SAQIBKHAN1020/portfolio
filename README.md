# Saqib Khan — Portfolio

A responsive portfolio for Saqib Khan, focused on applied AI and product engineering.

## Stack

- React 18
- Vite
- Custom responsive CSS
- Lightweight Intersection Observer reveals

## Local development

```bash
npm install
npm run dev
```

Create a production build with `npm run build`.

## Content and assets

- Profile details and projects: `src/data/content.js`
- Portfolio images: `public/images/`
- Résumé: `public/Saqib_Khan_CV.pdf`

The current portrait and project covers are AI-generated placeholders. Replace them with real photography and product screenshots when available.

The contact form opens a pre-filled message in the visitor's default email client, so it works without exposing API keys or requiring a backend.
